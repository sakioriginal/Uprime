# Lineage VR v0.2 - Sword & Enemy

Meta Quest 3S / GitHub Pages 向けの A-Frame VR 試作です。

## 今回入っている機能

- VR空間を歩く
- 右手コントローラーで剣を掴む
- 剣を振ると敵にダメージ
- 敵HPバー
- プレイヤーHP
- 敵が近づいて攻撃
- 倒すと経験値
- レベルアップで攻撃力とHP上昇
- PC確認用：クリックで攻撃、WASDで移動

## GitHub Pages

このZIPを解凍して、以下をリポジトリ直下にアップロードしてください。

- index.html
- css/
- js/
- assets/
- saves/
- README.md

Pages は main / root で公開します。

## 操作

### Quest 3S

1. Quest BrowserでURLを開く
2. VRに入る
3. 右手トリガー、またはグリップで剣を掴む
4. 剣を振って敵に当てる

### PC

- WASD: 移動
- マウス: 視点
- クリック: 攻撃
