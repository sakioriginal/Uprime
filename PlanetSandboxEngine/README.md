# Planet Sandbox Engine Static v0.1

GitHub Pages 用の **ビルド不要版** です。

## 使い方

`PlanetSandboxEngine/` フォルダをそのまま GitHub Pages 配下にアップロードしてください。

例:

```text
Uprime/
└─ PlanetSandboxEngine/
   ├─ index.html
   ├─ style.css
   └─ main.js
```

URL:

```text
https://sakioriginal.github.io/Uprime/PlanetSandboxEngine/
```

## 注意

- `src/main.ts` は使いません。
- Vite / npm / TypeScript のビルドは不要です。
- GitHub Pages に置くだけで動く構成です。

## 現在の機能

- Three.js 球体惑星
- 高低差つき地形
- 海、大気、雲、太陽、月、他惑星、星空
- FPV / TPV / RTS / Planet スケールカメラ
- PC: WASD + マウス + ホイール
- スマホ: 左右スティック + ABXY + ＋－
- NPC会話、忠誠心、信仰心の土台
- 採集、建売住宅建築
