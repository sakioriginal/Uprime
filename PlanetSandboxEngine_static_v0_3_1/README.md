# Planet Sandbox Engine v0.3.1

GitHub Pagesでそのまま動く静的版です。

## v0.3.1 追加
- パラメトリック寸法入力
- 体積計算
- 素材密度による重量計算
- 武器/アイテム使用時のスタミナ消費計算
- 設計図のlocalStorage保存/読込
- holdPose / carryPose / sheathPose 追加
- 手に持った時、背中に背負った時、腰に差した時の位相データを保存
