# Planet Sandbox Engine v0.1.5

GitHub Pages対応・ビルド不要版。

## 更新内容
- 主人公・村人をカプセルから簡易ヒューマノイドに変更
  - 頭、胴体、腕、手、脚、足
  - 目、鼻、口、耳、眉、髪型の土台
- 犬・馬・狼・猪などを簡易クリーチャーモデルに変更
  - 胴体、頭、耳、脚、尾
- 主人公が横倒しになる問題をさらに修正
  - ローカルY軸を地面法線に固定
  - ローカルZ軸を進行方向に固定
  - 前回進行方向を保持して姿勢を安定化
- 村人・クリーチャーの移動速度を少し低速化
- グループ化したキャラをタップ/クリック選択できるように修正

## 配置
Uprime/PlanetSandboxEngine/ に以下を配置してください。

- index.html
- style.css
- main.js
- README.md

## 注意
ローカルで確認する場合は index.html を直接開かず、簡易サーバーを使ってください。

```bash
python -m http.server 8000
```
