# PlanetSandboxEngine v0.2.0

- 弓の形をS字からΩ字に近い対称カーブへ変更
- 弓・矢・剣の手元位置を微調整
- 矢の発射位置をVR空間から惑星シミュレーション座標へ変換

配置：`PlanetSandboxEngine/` 内へ `index.html`, `style.css`, `main.js`, `README.md` を上書きしてください。
